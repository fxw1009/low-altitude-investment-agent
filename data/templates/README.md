# 可直接填写的数据模板

每个人先复制自己任务对应的 `.template.csv` 为正式文件，再逐行填写。**一行就是一条可核验记录，不是一段总结。**

| 负责人 | 复制模板 | 正式文件 |
|---|---|---|
| 武桐宇 | `nodes.template.csv`、`relations.template.csv`、`company_mapping.template.csv` | `data/graph/` 下对应文件 |
| 刘芯妤 | `events.template.csv`、`evidence.template.csv` | `data/` 下对应文件 |
| 范笑薇 | `wind_financials.template.csv`、`impact_score.template.csv` | `data/` 下对应文件 |

填写前请阅读 [数据收集与交付标准](../../docs/DATA_COLLECTION_STANDARD.md)。原始链接打不开、没有发布日期或无法指出网页/公告位置时，该条记录不能标为 `verified`。
